# ScaleTrack - 产品需求文档 (PRD)

## 产品概述

ScaleTrack 是一款本地化的体重与 BMI 追踪应用，帮助用户记录每日体重变化、可视化趋势数据，并通过目标设定与里程碑激励用户保持健康习惯。

- **平台**：Web H5（移动优先，适配 430px 视口）
- **数据存储**：浏览器 localStorage，支持 JSON 导入/导出
- **主题**：支持 Dark / Light 模式切换

## 核心功能

### 1. 初始化设置

用户首次使用时需填写基础信息：

| 字段     | 类型         | 说明              |
| -------- | ------------ | ----------------- |
| 性别     | 男 / 女      | 影响 BMI 参考区间 |
| 身高     | cm（50-250） | 计算 BMI 必需     |
| 当前体重 | kg（20-300） | 作为体重锚点      |

- 填写过程中实时预览 BMI 值及分级
- 信息后续可在主页修改（身高）

### 2. 每日体重记录

| 项   | 说明                           |
| ---- | ------------------------------ |
| 频率 | 每天一次                       |
| 日期 | 用户可选择（支持补填遗漏记录） |
| 体重 | kg，精确到 0.1                 |
| BMI  | 根据体重和身高自动计算         |
| 差值 | 自动显示与上次记录的体重变化   |

- 同一天重复记录会覆盖旧数据
- 历史记录可删除

### 3. 数据可视化（折线图）

**图表类型**：双 Y 轴折线图

- 左轴：体重（kg）
- 右轴：BMI
- 数据点按 BMI 分级着色，直观反映健康状态

**时间范围**：

| 范围 | 说明     |
| ---- | -------- |
| 3天  | 近期趋势 |
| 7天  | 周趋势   |
| 1月  | 月度变化 |
| 3月  | 长期趋势 |

### 4. BMI 分级标准（中国标准）

| 分级 | 范围      | 颜色           | 说明                               |
| ---- | --------- | -------------- | ---------------------------------- |
| 偏瘦 | < 18.5    | 蓝色 `#3b82f6` | 体重过轻，建议适当增加营养         |
| 正常 | 18.5 ~ 24 | 绿色 `#22c55e` | 体重正常，请继续保持               |
| 偏胖 | 24 ~ 28   | 橙色 `#f59e0b` | 体重偏重，建议适当控制饮食和运动   |
| 肥胖 | ≥ 28      | 红色 `#ef4444` | 体重过重，建议咨询医生制定减重计划 |

**计算公式**：

```
BMI = 体重(kg) ÷ 身高(m)²
```

页面底部展示完整的 BMI 分级说明和计算公式。

### 5. 目标设定

| 功能     | 说明                     |
| -------- | ------------------------ |
| 设定目标 | 输入目标体重（kg）       |
| 进度追踪 | 进度条显示当前进度百分比 |
| 差值提示 | 显示距离目标还差多少 kg  |
| 达成庆祝 | 弹窗展示 + confetti 动画 |

**达成弹窗内容**：

- 总用时（天）
- 总减/增重（kg）
- 平均每天变化（kg）
- 起始体重 → 目标体重可视化
- 根据用时长短给出不同鼓励语
- 可保存为图片（PNG）分享到社交平台
- 提供「设定新目标」和「稍后再说」按钮

**图片分享卡片设计**：

- 顶部渐变色头部（品牌色 + 成就图标）
- 中部三栏统计数据
- 体重旅程可视化（起始 → 目标）
- 鼓励语
- 底部品牌标识
- 使用 html-to-image 生成，3x 像素密度，白色背景

### 6. 里程碑

- 首个达成的目标会作为里程碑永久保存
- 展示：起始体重 → 目标体重、总变化量、用时、达成日期
- 以列表形式展示在独立卡片中

### 7. 数据管理

| 功能 | 格式 | 说明                                  |
| ---- | ---- | ------------------------------------- |
| 导出 | JSON | 包含 profile、records、goals 全部数据 |
| 导入 | JSON | 校验格式后导入，成功后自动刷新        |

## 数据模型

### UserProfile

```typescript
interface UserProfile {
  gender: 'male' | 'female'
  height: number // cm
  initialWeight: number // kg
  createdAt: string // ISO string
}
```

### WeightRecord

```typescript
interface WeightRecord {
  id: string
  date: string // YYYY-MM-DD
  weight: number // kg
  bmi: number
  createdAt: string // ISO string
}
```

### Goal

```typescript
interface Goal {
  id: string
  targetWeight: number
  startWeight: number
  startDate: string
  completedDate?: string
  isCompleted: boolean
}
```

### ExportData

```typescript
interface ExportData {
  version: 1
  exportedAt: string
  profile: UserProfile | null
  records: WeightRecord[]
  goals: Goal[]
}
```

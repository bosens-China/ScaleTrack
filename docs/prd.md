# ScaleTrack - 产品需求文档 (PRD)

## 产品概述

ScaleTrack 是一款本地化的体重与 BMI 追踪应用，帮助用户以移动端 H5 方式记录日常体重、查看趋势、维护目标，并在本地完成数据导入与导出。

- **平台**：Web H5（移动优先，适配 430px 视口）
- **数据存储**：浏览器 localStorage，支持 JSON 导入/导出
- **当前主题**：浅色模式（Light）
- **当前视觉方向**：Carbon 风格，轻量企业感与数据工具气质

---

## 当前版本目标

当前版本聚焦于三个核心问题：

1. 快速完成首次基础资料设置
2. 高频、低负担地记录每日体重
3. 在移动端清晰查看趋势、BMI 与目标状态

---

## 信息架构

当前版本采用 **4 个底部 Tab** 的结构：

| Tab | 页面     | 主要职责                                                |
| --- | -------- | ------------------------------------------------------- |
| 1   | 仪表盘   | 展示当前体重、BMI、最近进度、目标与最近记录             |
| 2   | 趋势     | 查看体重趋势、区间统计和简要洞察                        |
| 3   | 添加     | 使用刻度尺记录当日体重并填写备注                        |
| 4   | 个人中心 | 管理目标、查看 BMI 信息、编辑基础资料、导入导出本地数据 |

## 核心功能

### 1. 首次使用设置

用户首次进入应用时，需要先完善基础资料。

| 字段     | 类型         | 说明             |
| -------- | ------------ | ---------------- |
| 性别     | 男 / 女      | 用于个人资料展示 |
| 身高     | cm（50-250） | BMI 计算必需     |
| 当前体重 | kg（20-300） | 作为初始体重     |

规则：

- 设置流程为应用内首次设置，不作为独立品牌启动页
- 填写过程中实时预览 BMI 值及分级
- 后续可在个人中心修改性别与身高

### 2. 每日体重记录

“添加”页负责完成当日体重录入。

| 项       | 说明                                     |
| -------- | ---------------------------------------- |
| 记录方式 | 横向刻度尺选择体重                       |
| 体重精度 | 0.1 kg                                   |
| 日期     | 当前日期                                 |
| 备注     | 选填，用于记录晨起、饭后、运动后等上下文 |

规则：

- 同一天再次保存会覆盖旧记录
- 若当日已有记录，页面需明确提示“再次保存会覆盖今天的记录”
- 覆盖时保留同一条记录的日期语义，不新增重复日记录

### 3. 仪表盘

仪表盘用于承接最重要的即时状态。

展示内容：

- 当前体重
- 与上一条记录相比的变化值
- 当前 BMI 与 BMI 分级标签
- 最近 7 天微型趋势图
- 目标体重与进度条
- 每周体重变化（增加 / 减少 / 持平）
- 最近一条记录的日期、体重、备注

空状态规则：

- 若还没有体重记录，仪表盘不展示低价值占位信息
- 空状态只保留引导性说明和“添加体重记录”入口

### 4. 趋势页

趋势页用于查看最近区间的体重变化。

当前版本展示：

- 时间范围切换：`3天 / 7天 / 15天 / 1个月`
- 单条体重折线图
- 区间统计：最高、最低、平均体重
- 文本洞察

规则：

- 当前版本仅展示体重趋势，不展示 BMI 双轴图
- 若当前区间无数据，展示精简空状态与跳转添加入口

### 5. BMI 信息

应用基于中国常用 BMI 分级展示状态说明。

| 分级 | 范围      | 颜色                       | 说明                             |
| ---- | --------- | -------------------------- | -------------------------------- |
| 偏瘦 | < 18.5    | 蓝色 `#3b82f6`             | 体重偏轻，建议适当增加营养       |
| 正常 | 18.5 ~ 24 | 蓝色主信息区内正常标签展示 | 体重正常，请继续保持             |
| 偏胖 | 24 ~ 28   | 黄色提示区                 | 体重偏重，建议适当控制饮食和运动 |
| 肥胖 | ≥ 28      | 浅红提示区                 | 体重过重，建议关注长期健康管理   |

计算公式：

```text
BMI = 体重(kg) ÷ 身高(m)²
```

当前展示位置：

- 仪表盘摘要卡
- 个人中心 BMI 信息模块

### 6. 目标设定

目标功能集中在个人中心。

| 功能         | 说明                               |
| ------------ | ---------------------------------- |
| 设置目标体重 | 输入目标体重（kg）                 |
| 进度追踪     | 计算当前体重到目标体重的完成百分比 |
| 状态展示     | 展示当前体重、目标体重、距离目标   |

当前规则：

- 只保留一个活动目标
- 达成目标后自动归档到本地 goals 数据中
- 当前版本未展示独立“里程碑列表”页面

### 7. 本地数据管理

个人中心支持本地数据导入导出。

| 功能 | 格式 | 说明                             |
| ---- | ---- | -------------------------------- |
| 导出 | JSON | 导出基础资料、体重记录、目标数据 |
| 导入 | JSON | 导入后刷新本地状态               |

## 设计规范

### 视觉方向

- 风格：Carbon 风格
- 气质：清晰、克制、工具感、数据优先
- 原则：减少装饰性元素，优先信息密度与可读性

### 主题色

| 角色       | 值        |
| ---------- | --------- |
| 背景       | `#ffffff` |
| 次级背景   | `#f4f4f4` |
| 文字       | `#161616` |
| 次级文字   | `#525252` |
| 边框       | `#e0e0e0` |
| 主色       | `#0f62fe` |
| 主色 Hover | `#0043ce` |
| 主色浅底   | `#d0e2ff` |

### 字体

当前版本优先使用系统中文字体栈：

```text
PingFang SC
Hiragino Sans GB
Noto Sans CJK SC
Source Han Sans SC
Microsoft YaHei
Helvetica Neue
-apple-system
system-ui
```

原则：

- 中文优先可读性
- 避免依赖远程 Web Font 造成加载抖动
- iOS 优先使用 `PingFang SC`

### 间距与安全区

- 适配移动端安全区（`safe-area-inset-top / bottom / left / right`）
- Header 与 Bottom Tab 使用统一安全区变量
- 底部操作按钮需避开 iOS Home Indicator

## 数据模型

### UserProfile

```ts
interface UserProfile {
  gender: 'male' | 'female'
  height: number // cm
  initialWeight: number // kg
  createdAt: string // ISO string
}
```

### WeightRecord

```ts
interface WeightRecord {
  id: string
  date: string // YYYY-MM-DD
  weight: number // kg
  bmi: number
  note?: string
  createdAt: string // ISO string
}
```

### Goal

```ts
interface Goal {
  id: string
  targetWeight: number
  startWeight: number
  startDate: string
  completedDate?: string
  isCompleted: boolean
}
```

### ExportData

```ts
interface ExportData {
  version: 1
  exportedAt: string
  profile: UserProfile | null
  records: WeightRecord[]
  goals: Goal[]
}
```

## 当前版本已知边界

- 当前版本仅支持浅色模式
- 当前趋势页仅展示体重，不展示 BMI 双轴趋势
- 当前不提供独立里程碑列表展示
- 当前记录日期固定为当天，不支持补填历史日期
